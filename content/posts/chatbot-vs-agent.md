## 세 가지 차이

|  | 챗봇 | 에이전트 |
| --- | --- | --- |
| **손** | 말로만 답한다 | 파일을 고치고, 시스템을 호출하고, 메일을 보낸다 |
| **반복** | 한 번 묻고 한 번 답한다 | 계획 → 실행 → 결과 확인 → 다음 행동을 **스스로** 반복한다 |
| **끝** | 답을 하면 끝 | **목표에 닿았는지 판정**하고, 아니면 다시 한다 |

## 그래서 가능해지는 것

- "자료 찾아서 정리해 줘"가 **파일로 나옵니다.** 내가 옮겨 적지 않습니다
- 중간에 틀리면 **스스로 다시 합니다.** 내가 매번 지적하지 않습니다
- 여러 단계 작업을 **한 번 시키면 끝까지** 갑니다

## 그래서 위험해지는 것

손이 생기면 사고도 손으로 납니다. 챗봇이 틀리면 틀린 문장이 남고,
에이전트가 틀리면 **틀린 결과가 실행되어** 남습니다.

- **되돌릴 수 없는 동작** — 삭제, 전송, 결제. 한 번 나가면 끝입니다
- **권한 범위** — 무엇을 읽을 수 있고 무엇을 바꿀 수 있는지를 내가 정해 줬는지
- **조용한 실패** — 뭔가 한 것 같은데 실제로는 아무 일도 안 일어난 경우. 확인하지 않으면 모릅니다

## 어디까지 맡기고 어디서 끊나

기준은 단순합니다. **되돌릴 수 있는 것부터.**
